# Three-repository audit: 2026-11-15

Reviewed the complete working implementations, tests and packaging in Control4-HA-Switch, Control4-HA-Coordinator and HA-Gesture-Bridge, including untracked implementation files. The audit found **2 High, 14 Medium and 2 Low** issues, grouped below. All verified findings were fixed before LED implementation; the most important correction releases forwarded holds when HA transport goes offline.

Working-tree bases: Switch `f55526b`, Coordinator `dccd545`, HA companion `16ec8b2`. Source locations below identify the audit baseline; subsequent LED additions can move line numbers.

This is a local development audit, not a hardware qualification or a claim that all possible defects have been eliminated. The audit used the `audit-code` skill and independent runtime, coordinator, HA and tests reviews, followed by source verification and cross-repository regressions.

## 2. Security & error handling

| Severity | Finding and resolution | Source |
|---|---|---|
| High | REST used HTTP even when SSL was selected, exposing bearer credentials on that path. REST now derives HTTPS and certificate options from current properties, verifies peer/host and rejects redirects; WSS verifies peers too. | `../Control4-HA-Coordinator/driver.lua:782` |
| High | A forwarded hold survived real coordinator transport loss because children only saw physical binding changes.
